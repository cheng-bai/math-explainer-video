# 从知识笔记到可视化讲解

## 内容层

教材用于定位定义、定理与原始推导，教参用于教学重点、障碍和方法联系。先写知识笔记，再制作视频。两类输入分别提供来源；新增反例、迁移或统一模型标为教学重构，不冒充教材原例。

笔记要回答：概念解决什么问题、为什么选这一步、推导依据是什么、哪一步容易卡住、哪些条件不可删、能迁移到哪里。章节梳理不是逐条展示公式；长章节宜围绕一个模型串联不同方法。

## 教学步骤与数学模型

将每个证明节点对应到一次可见动作：平移、分解、投影、筛选、比较或变形。记录变量范围、坐标、从属关系、保持不变的条件和关键帧数值。图形、角标、垂足、公式读数来自同一个模型；所有坐标轴按相同单位长度绘制，避免把真实直角画歪。

一般证明和数值图示分开：一组数值可以帮助观察，不能代替对所有情形的证明。边界如零向量、分母为零、垂足在线段外须单独解释。

## 画布与连续性

先分配三个位置：已得到的依据、当前操作、下一步任务。同一推导保留关键对象；新公式逐步加入，完成部分收纳到仍可读的区域。镜头放大当前对象时不要让历史依据缩成无法辨认的缩略图。

静态截图不能证明“动画解释清楚”。检查中间帧：箭头有没有反向、标签是否跟随、垂足是否同步、旋转是否越界。例子中的三场会沿用同一坐标模型并保留已推出的关系；复杂长视频需要作者进一步安排镜头和归档。

## 讲解、配音、时轴

讲解稿读成自然中文，例如“二分之根号三”，而不是LaTeX。每段配音单独缓存，先获取实际时长再安排动作。默认中文男声zh-CN-YunxiNeural，在线生成；也可在本地制作静音样片。

`duration_s`是动画预算；`audio_duration`是实际音频时长。Scene必须在预算内结束，不通过裁切掩盖超时。字幕按分句字数估计，视觉触发也可估计或手工调整；目前没有强制对齐功能。

## 回收、审查、交付

最终全貌图重新排版，只保留关键推导、条件、对象定义与结论，避免拼接一堆截图。PDF是高分辨率图像封装，不宣称公式可搜索或全矢量。

分别检查数学、视觉、音画和文件完整性。解码器仅验证技术完整；数学推理需独立复核或第二遍自查。使用真实学生作答判断是否学会，未收集证据时不宣称学习效果已验证。

CLI自动完成配音/渲染/拼接/字幕/解码；知识笔记、证明、分镜、动画源码与教学审查仍由Agent或作者完成。
