# 从知识笔记生成动画

输入笔记时读取结论与条件、教材推导节点、可执行动画约定、来源与复核边界。输出前建立“笔记节点 → 场景”的对应，不能用另一种熟悉证明替换用户选定路线。

- 将输入变量与范围、对象坐标、从属关系、不变量、关键帧转成同一个数学模型。依赖标签、线段、读数随模型更新，不能靠各自插值假装满足关系。
- 一般证明与数值图示区分；参数化轨迹是绘图工具，不能作为尚未证明结论的依据。示例限制如固定和、正项不得偷偷成为定理限制。
- 核对等号、边界、退化情形与平方变形的符号；不支持的边界用独立场景解释，不强行代入失效公式。
- 按笔记给出的关键帧数值与全过程不变量检查实现，最后仍须抽帧检查画面、同步标签与动作关键时刻。
- 笔记缺少关键坐标或参数时，先据数学补齐并注明补充；若缺少条件会改变结论则澄清。不要依靠猜测生成图形。

用户仅要求知识笔记时，本技能的成片流程只用于明确约定的试渲染；短无声验证不得标为完整讲解视频。
