# 数学视觉与验收

## 本流程已验证的两个模式

- 空间几何计数：实际坐标 → 等距条件 → 分类 → 表面/端点筛选 → 代回核验。投影可以是示意图，但不能把非正四面体画成正四面体后按其性质推理。
- 三角公式：单位圆有向坐标 → 对称/坐标交换 → 旋转正交基与分解 → 比较横纵坐标 → 和差角/倍角。图中使用锐角时明确公式的实际适用范围。

这两个模式只是例子，不限制后续函数、数列、概率或其它高中数学题型。

## 易出错处

- Python 的 `\frac`、`\text`、`\times`、`\boxed` 需要 raw string，避免控制字符破坏 LaTeX。
- 动点改变象限或位置后，投影线、坐标标签、角弧、长度标注应同步；不能只移动圆点，保留旧角标。
- 公式除法、平方、开方及函数定义域要标出真实条件。度数与弧度标签不要混写。
- 正余弦是有符号坐标；空间投影位置不能替代真实距离计算。
- 向量基方向和旋转正负直接决定符号，绘图方向必须与推导一致。
- 下方卡片可能遮住顶点标签或图注；字幕需与卡片、章号分开。尽量为手机观看放大核心公式，长公式分行或分镜，而非一直缩小。

## 验收动作

抽取开场、关键推导、候选点/端点、最终答案帧，并检查动作中间帧。对每个可见标签确认其数学对象；看交点、方向、符号和端点，而不只看美观。播放关键声音段检查数学读法和配音是否对应画面。
