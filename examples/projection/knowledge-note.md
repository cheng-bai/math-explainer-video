# 投影为什么能连接角度与数量积？

本例为项目原创教学设计。使用通用的向量定义及余弦关系，无教材原文、私人来源或外部题干。

## 目标与动机

沿一个固定方向读取另一个向量的贡献，可以区分向量投影与带符号的数量投影，再理解数量积如何判断垂直。前置：向量大小与方向、余弦的有符号意义。

## 模型、条件与推导

O=(0,0)，a=(3,0)，b(θ)=2(cosθ,sinθ)，H=(2cosθ,0)，θ∈[0,π]。本例a、b非零，横纵坐标单位等长。

1. 向量OH为b沿a方向的投影向量；数量投影s=2cosθ，可以为负；其模为|s|，非负。
2. a·b=|a|s=6cosθ，区分箭头和实数。
3. 两个非零向量的夹角在[0,π]，cosθ=0当且仅当θ=π/2，所以数量积为零当且仅当垂直。
4. 零向量数量积另行规定为零，不由此定义唯一夹角。图示只是固定模的例子，不能把|a|=3、|b|=2写成一般定理条件。

## Scene映射与关键帧

| 场景 | 当前操作 | 保留依据 | 下一任务 |

| Scene01 | 构造投影 | 非零a，b长度2 | 角度改变会怎样 |
| Scene02 | θ从30°到90°再到130° | s=2cosθ | 将贡献变为数量积 |
| Scene03 | 引入a·b=3s并回到90° | 有符号投影 | 核对非零条件 |

θ=30°：s=√3，dot=3√3；90°：s=dot=0，投影用点表示；130°：s≈−1.286，dot≈−3.857。全程|b|=2，BH垂直横轴，H的纵坐标为0；向量、角弧、H与读数由同一个θ驱动。

## 学习检测

θ=0与π时，数量积分别是什么符号？若|a|改为5，H是否移动，数量积是否改变？数量积为零时，为何还要确认向量非零？
